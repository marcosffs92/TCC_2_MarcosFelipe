# Sistema de Manutenção Preventiva

Protótipo acadêmico desenvolvido para o TCC de Engenharia de Software.

## Tecnologias
- Node.js 22 ou superior
- JavaScript
- HTML e CSS
- SQLite por meio do módulo `node:sqlite`

## Como executar
1. Instale o Node.js 22 ou superior.
2. Abra o terminal na pasta do projeto.
3. Execute `npm start` ou `node server.js`.
4. Acesse `http://localhost:3000` no navegador.

Não é necessário instalar bibliotecas externas. O banco `data/manutencao.db` é criado automaticamente na primeira execução.
